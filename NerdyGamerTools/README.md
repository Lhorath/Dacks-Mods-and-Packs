# NerdyGamerTools

**NerdyGamerTools** is the publishing namespace for **original mods and tools developed and released by NerdyGamerTools/Lhorath**.

The intent of this namespace is different from DabosGG:

- **NerdyGamerTools** = original software releases;
- **DabosGG** = server-specific curated mods/modpacks for Dabos.GG game servers.

## Legacy modpack exception

**The_Nerdy_AzuPack** is a historical curated modpack created before this namespace distinction was formalized.

It remains under NerdyGamerTools to preserve repository/package history, but it should not be treated as the model for future NerdyGamerTools releases. Newly curated server modpacks should use the **DabosGG** namespace.

See the repository [Namespace and Attribution Policy](../docs/NAMESPACE-POLICY.md).
