# NerdyGamerTools — Deep North 3.0

**NerdyGamerTools is the namespace for original mods and tools developed and released by NerdyGamerTools/Lhorath.**

This is intentionally separate from **DabosGG**, which is used for curated Dabos.GG server packages and modpacks.
