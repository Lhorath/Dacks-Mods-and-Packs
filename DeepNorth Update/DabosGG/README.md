# DabosGG — Deep North 3.0

**DabosGG is the server-package namespace for Dabos.GG game servers.**

Packages here are curated specifically for Dabos.GG deployments. Third-party mods remain the work of their respective creators and are credited in each modpack's `CREDITS.md`.

## Modpacks

- [Vanilla Server Pack 3.0.0](MODPACKS/DabosGG_Vanilla_Server_Pack/DabosGG-DabosGG_Vanilla_Server_Pack-3.0.0/) — QoL/server baseline including NerdyGamerTools AutoBroadcaster.
- [New Skills Pack 3.0.0](MODPACKS/DabosGG_New_Skills_Pack/DabosGG-DabosGG_New_Skills_Pack-3.0.0/) — skill/progression pack under rebuild.
- [New Content Pack 3.0.0](MODPACKS/DabosGG_New_Content_Pack/DabosGG-DabosGG_New_Content_Pack-3.0.0/) — gameplay/content expansion pack.
- [Modded Server Pack 3.0.0](MODPACKS/DabosGG_Modded_Server_Pack/DabosGG-DabosGG_Modded_Server_Pack-3.0.0/) — aggregate of the three component packs.

## Standalone mods/configuration packages

The DabosGG namespace may also contain server-specific mods or configuration packages when they are intended specifically for Dabos.GG game servers.

For original general-release mods developed by NerdyGamerTools/Lhorath, use the **NerdyGamerTools** namespace instead.

See [Namespace and Attribution Policy](../../docs/NAMESPACE-POLICY.md).
