# DabosGG

**DabosGG** is the repository namespace for packages assembled specifically for **Dabos.GG game servers**.

This includes:

- curated server modpacks;
- server-specific mod/configuration bundles;
- Dabos.GG-specific compatibility or deployment packages.

DabosGG packages may contain dependencies created by many different Valheim mod authors. Those projects remain the work of their respective creators.

## Attribution

Every maintained DabosGG modpack must include a `CREDITS.md` or equivalent README credit section identifying the creators/namespaces behind its included third-party mods.

The active Valheim 1.0 / Deep North packages are under:

[DeepNorth Update / DabosGG](../DeepNorth%20Update/DabosGG/)

## Historical archive

The versioned folders in this namespace are preserved historical releases and are not rewritten solely to match current documentation.
