## Migration note

The package should be validated first because the DabosGG Modded Server Pack depends on it.

The archived 2.0.0 snapshot predates Valheim 1.0. Its dependency versions, configs, client requirements, and historical crossplay assumptions need to be tested again.

Its internal historical changelog stops before the 2.0.0 package version; that file is left unchanged to preserve the original release snapshot.
