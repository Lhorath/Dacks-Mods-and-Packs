# Dabos.GG Vanilla Server Modpack

## Description
This is a QoL Package that includes a few mods to make vanilla gameplay a little more enjoyable. This package contains no mods that interfere with the base game so Crossplay users will not be negatively affected.

`This Package is also required for our modded server!`

## Default Keybinds

Keybinds can Be Found here [**Dabos Vanilla Pack Wiki**](https://thunderstore.io/c/valheim/p/DabosGG/DabosGG_Vanilla_Server_Pack/wiki/1807-hotkeys/)

## Compatibility
Here is a list of mods that should not be installed based on compatibility issues with the pack:
```
FarmGrid
MassFarming
Farming
Valheim+
```
