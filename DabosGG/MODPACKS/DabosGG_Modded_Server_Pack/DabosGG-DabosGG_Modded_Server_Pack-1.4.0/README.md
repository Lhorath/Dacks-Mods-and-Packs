### Version 1.4.0  

## Description
![Dabos.GG Gameservers!](https://dabos.gg/dabos_mods/modserver_banner_description.png)

This is a package built to bundle other mod packs and configuration files in order to play on Dabos.GG Modded Server.

 💥 ***This Modpack is Required in order to connect to the Dabos.GG Modded Server*** 💥

 ## Compatibility
 Here is a list of mods that should not be installed based on compatibility issues with the pack:
 ```
 FarmGrid
 MassFarming
 Farming
 Valheim+
 ```
