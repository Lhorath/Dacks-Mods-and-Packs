# Dabos.GG New Skills Server Modpack

## Description  

This package was built for Dabos.GG Servers to bring new skills and bonuses to the game and fill some gaps.

`This Package is required for our modded server!`

## Compatibility
Here is a list of mods that should not be installed based on compatibility issues with the pack:

- Farming Can Not Be Added as Causes issue with other Dabos ModPacks
